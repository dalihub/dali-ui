# InputField Focus

InputField의 탭 포커스 획득 및 ESC 키로 포커스 해제가 정상 동작하는지 확인한다.

## 화면 구성

- 상단: 현재 포커스 상태를 표시하는 라벨
- 중앙: 2개의 InputField (각각 플레이스홀더 텍스트 포함)
- 포커스를 받은 InputField은 연한 주황색 배경으로 변경됨

## 테스트 1: 탭으로 포커스 획득

1. Field 1을 탭한다
2. **기대 결과**: Field 1 배경이 주황색으로 변경, 상단에 "Focused: Field 1" 표시, 키보드(IME) 활성화
3. Field 2를 탭한다
4. **기대 결과**: Field 1 배경 복귀, Field 2 주황색, 상단 "Focused: Field 2"

## 테스트 2: ESC로 포커스 해제

1. Field 1을 탭하여 포커스를 준다
2. ESC 키를 누른다
3. **기대 결과**: 포커스가 해제되고, 상단에 "Focused: (none) - ESC cleared focus" 표시, 양쪽 Field 모두 원래 배경색

## 테스트 3: 텍스트 입력

1. Field 1을 탭하여 포커스를 준다
2. 키보드로 텍스트를 입력한다
3. **기대 결과**: Field 1에 텍스트가 표시됨
4. Field 2를 탭하여 포커스를 이동한다
5. **기대 결과**: Field 1의 텍스트 유지, Field 2에 새로운 텍스트 입력 가능

## 통과 기준

- 탭으로 InputField에 포커스를 줄 수 있어야 한다
- 롱프레스로도 포커스를 줄 수 있어야 한다
- ESC 키로 포커스를 해제할 수 있어야 한다
- 포커스 상태가 시각적으로(배경색) 정확히 반영되어야 한다
- FocusChangedSignal로 포커스 변경이 정확히 통지되어야 한다

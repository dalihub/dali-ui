# 63. FlexLayout: Wrap Content Grow

최소 폭을 가진 WRAP_CONTENT FlexLayout에서 grow 자식이 추가 공간을 받는지 확인한다.

## 화면 구성

- 최소 폭 400·높이 200 root
- 고정 폭 200 빨강
- 나머지 200을 받는 초록과 내부의 동일 grow 파랑·노랑

## 테스트 절차

1. 네 색상 영역의 폭을 비교한다.
2. **기대 결과**: root 400px 안에서 빨강과 초록이 200px씩 차지하고 파랑과 노랑이 초록을 100px씩 나눈다.

## 통과 기준

- 최소 크기로 생긴 여유 공간이 중첩 grow 단계마다 정확히 분배된다.

# 47. AbsoluteLayout: Overlap

AbsoluteLayout 자식의 겹침과 add order 기반 그리기 순서를 확인한다.

## 화면 구성

- 빨강 400x400, 초록 200x200, 파랑 100x100의 중첩
- 부모 중앙에 비례 배치된 청록 50x50

## 테스트 절차

1. 겹치는 영역의 색상 순서를 확인한다.
2. **기대 결과**: 나중에 추가된 초록이 빨강 위에, 파랑이 두 사각형 위에, 청록이 가장 위에 보인다.

## 통과 기준

- 겹침이 잘리지 않고 add order에 따른 Z-order가 유지된다.

# 72. Standalone: View

plain View에서 STANDALONE 자식이 부모 layout 계산과 일반 자식 배치에서 제외되는지 확인한다.

## 화면 구성

- 일반 빨강·초록 자식과 초록 내부 노랑
- 요청 좌표 `(300, 300)`의 standalone 파랑 100x100

## 테스트 절차

1. 파랑과 일반 자식의 위치를 비교한다.
2. **기대 결과**: 파랑은 다른 자식의 margin/WRAP_CONTENT 계산과 무관하게 정확히 `(300, 300)`에 놓인다.

## 통과 기준

- standalone 자식이 일반 자식의 크기 또는 위치를 밀어내지 않는다.

# 62. FlexLayout: Shrink

basis 합이 컨테이너를 넘을 때 FlexShrink 비율을 확인한다.

## 화면 구성

- basis 250인 자식 세 개의 기본 shrink 행
- shrink 0/1/3을 적용한 비교 행

## 테스트 절차

1. `Parent: Width 700 (Shrink)`을 누르고 첫 행의 세 폭을 비교한다. outer와 각 행의 좌우 padding 합 200을 제외한 아이템 가용 폭은 500이다.
2. **기대 결과**: 기본 shrink=1이어서 세 자식이 각각 약 166.67로 줄어든다.
3. 둘째 행을 확인한다.
4. **기대 결과**: 폭은 250/187.5/62.5가 된다. 첫 자식은 250을 유지하고 둘째·셋째의 축소량은 62.5/187.5로 1:3이다.
5. `Parent: Full`을 누른 뒤 다시 700으로 전환하여 반복 결과가 같은지 확인한다. Full의 가용 폭이 750 이상이면 세 자식은 각각 basis 250을 유지한다.

## 통과 기준

- overflow 공간이 shrink 가중치에 따라 분배되며 자식이 겹치지 않는다.

## 측정 조건 및 제한

- 수치는 effective scale=1 기준이다. 일반적으로 shrink 가중치는 `shrink × 축소 전 크기`이며 이 TC는 세 basis가 같으므로 축소량이 0:1:3이다.
- outer 폭 500은 아이템 가용 폭을 300으로 만든다. 현재 구현은 음수 크기를 0으로 제한한 뒤 부족분을 재분배하지 않아 비교 행의 합계가 가용 폭을 넘을 수 있다. 기본 비율 검증에는 700 preset을 사용한다.
- 위 제한의 엔진 동작 개선은 이 매뉴얼 테스트 변경에 포함하지 않는다.

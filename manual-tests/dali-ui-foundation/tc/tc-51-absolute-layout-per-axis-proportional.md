# 51. AbsoluteLayout: Per-axis Proportional

축별 비례 플래그가 지정된 축에만 적용되는지 확인한다.

## 화면 구성

- 왼쪽의 높이 50% 노랑
- 위쪽의 폭 50% 파랑
- 우상단 고정 100x100 빨강
- 좌하단 고정 100x100 초록

## 테스트 절차

1. 창 크기를 변경하며 네 사각형을 확인한다.
2. **기대 결과**: 노랑은 높이만, 파랑은 폭만 변하고 빨강·초록은 크기를 유지한 채 해당 가장자리에 붙는다.

## 통과 기준

- X/Y/Width/Height 비례 플래그가 다른 축의 값에 영향을 주지 않는다.

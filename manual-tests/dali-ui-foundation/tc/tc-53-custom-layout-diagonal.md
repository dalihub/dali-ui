# 53. Custom Layout: Diagonal

View의 Measure/Arrange callback으로 세 자식이 대각선 배치되는지 확인한다.

## 화면 구성

- 50x50 빨강, 100x100 초록, 200x200 파랑
- 앞 자식의 우하단에서 다음 자식이 시작되는 대각선 구조

## 테스트 절차

1. 세 사각형의 접점과 전체 bounds를 확인한다.
2. **기대 결과**: 각 자식의 좌상단이 직전 자식의 우하단과 맞닿고 root가 전체 대각선 크기를 감싼다.

## 통과 기준

- callback 측정값과 배치 결과가 일치한다.

# 45. AbsoluteLayout: Basic

AbsoluteLayout이 자식을 지정된 픽셀 좌표와 크기로 배치하는지 확인한다.

## 화면 구성

- 흰 배경을 채우는 AbsoluteLayout
- 빨강 50x50 `(50, 50)`, 초록 100x100 `(100, 100)`, 파랑 100x50 `(200, 200)`

## 테스트 절차

1. TC에 진입해 세 사각형의 위치와 크기를 확인한다.
2. **기대 결과**: 각 사각형이 지정 좌표에 배치되고 서로의 위치 때문에 자동 재배치되지 않는다.

## 통과 기준

- 세 사각형의 좌상단과 크기가 지정한 `LayoutRect`와 일치한다.

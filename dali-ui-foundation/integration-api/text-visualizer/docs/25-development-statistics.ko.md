# TextVisualizer Development Statistics

## 1. 기준

이 문서는 `devel_text_visualizer` 브랜치에서 TextVisualizer 관련 작업이 어느 정도 누적되었는지 정리한다.

통계 기준은 다음과 같다.

| 항목 | 값 |
|---|---|
| 브랜치 | `devel_text_visualizer` |
| 시작 커밋 | `9970ed2009b9650167398ba5fc935a6d94a84f1f` |
| 시작 커밋 제목 | `docs: add text visualizer overview and pipeline analysis` |
| 통계 산출 시점 최신 구현 커밋 | `82f4977551c0034412faf9f17f205f107b73d57a` |
| 통계 산출 시점 최신 구현 커밋 제목 | `Design shared glyph cache helper for TextVisualizerGlyphRenderer` |
| 커밋 범위 | `9970ed2009b9650167398ba5fc935a6d94a84f1f^..82f4977551c0034412faf9f17f205f107b73d57a` |

시작 커밋도 TextVisualizer 문서 작업이므로, 기본 통계는 시작 커밋을 포함한 범위로 집계했다. 이 통계 문서를 추가하는 후속 커밋은 집계 대상에서 제외한다.

## 3. 최종 diff 기준 변화량

최종 diff 기준 변화량은 시작 커밋 직전 상태와 통계 산출 시점 최신 구현 커밋 상태를 비교한 값이다. 중간 커밋에서 추가했다가 다시 수정하거나 삭제한 line churn은 중복 계산하지 않는다.

| 범위 | 추가 | 삭제 | 순증 | 총 변화 |
|---|---:|---:|---:|---:|
| 전체 | 32,427 | 2 | 32,425 | 32,429 |
| 코드 / 샘플 / 테스트 (`docs/` 제외) | 18,643 | 2 | 18,641 | 18,645 |
| 문서 (`docs/`) | 13,784 | 0 | 13,784 | 13,784 |

코드 변화량만 볼 때는 `docs/` 제외 기준인 순증 `18,641` line을 대표값으로 보면 된다.

## 5. 커밋별 누적 churn

커밋별 누적 churn은 각 커밋의 `--numstat`을 모두 합산한 값이다. 같은 줄을 여러 커밋에서 반복 수정하면 그만큼 여러 번 계산되므로, 실제 최종 코드 증가량보다 크다.

| 범위 | 추가 | 삭제 | 순증 | 누적 변경 |
|---|---:|---:|---:|---:|
| 전체 | 35,836 | 3,411 | 32,425 | 39,247 |
| 코드 / 샘플 / 테스트 (`docs/` 제외) | 20,043 | 1,402 | 18,641 | 21,445 |
| 문서 (`docs/`) | 15,793 | 2,009 | 13,784 | 17,802 |

최종 결과물의 규모를 설명할 때는 최종 diff 기준을 사용하고, 개발 과정에서 실제로 어느 정도 수정이 오갔는지를 설명할 때는 누적 churn 기준을 사용한다.

## 6. 집계 명령

대표 집계 명령은 다음과 같다.

```sh
git rev-list --count 9970ed2009b9650167398ba5fc935a6d94a84f1f^..82f4977551c0034412faf9f17f205f107b73d57a
git rev-list --count 9970ed2009b9650167398ba5fc935a6d94a84f1f..82f4977551c0034412faf9f17f205f107b73d57a
git diff --numstat 9970ed2009b9650167398ba5fc935a6d94a84f1f^..82f4977551c0034412faf9f17f205f107b73d57a
git log --numstat --format= 9970ed2009b9650167398ba5fc935a6d94a84f1f^..82f4977551c0034412faf9f17f205f107b73d57a
```

`docs/` 제외 통계는 `awk`에서 path prefix가 `docs/`가 아닌 항목만 합산했다.

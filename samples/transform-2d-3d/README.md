# 2D / 3D Transform API Sample

This sample demonstrates the `View` extension APIs for per-axis position and
size together with the `Actor` orientation APIs.

Click each card to toggle its transform:

- 2D Position: `SetPositionX/Y`
- 2D Size: `SetSizeWidth/Height`
- 2D Orientation: `SetOrientationAngle`, using the default Z axis
- 3D Position: `SetPositionX/Y/Z`
- 3D Size: `SetSizeWidth/Height/Depth`
- 3D Orientation: Quaternion axis setup followed by `SetOrientationAngle`,
  preserving that axis

Press Escape or Back to quit.
